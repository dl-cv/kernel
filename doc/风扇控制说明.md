# RK3588 风扇功能说明（LubanCat 5IO）

## 1. 背景与目标

本次修改针对 `RK3588 + LubanCat 5IO` 平台风扇控制，目标是：

- 支持 3 种风扇模式：`silent`、`normal`、`turbo`
- 每种模式使用独立的温度-转速曲线
- 给上层应用提供可查询、可切换的标准 sysfs 接口
- 保留旧属性兼容，避免已有系统配置失效

---

## 2. 代码修改概览

### 2.1 设备树（DTS）修改

文件：`arch/arm64/boot/dts/rockchip/rk3588-lubancat-5io.dts`

在 `fan: pwm-fan` 节点中新增了 3 套曲线属性：

- `rockchip,cooling-levels-silent`
- `rockchip,temp-trips-silent`
- `rockchip,cooling-levels-normal`
- `rockchip,temp-trips-normal`
- `rockchip,cooling-levels-turbo`
- `rockchip,temp-trips-turbo`

同时保留兼容属性（等价 `normal`）：

- `cooling-levels`
- `rockchip,temp-trips`

> 说明：当前三种模式均为 8 档（state `0..7`），其中 `temp-trips-*` 提供 7 个切换点（对应进入 state `1..7`）。

### 2.2 驱动修改

文件：`drivers/hwmon/pwm-fan.c`

主要新增功能：

- 驱动内部支持 3 组 profile（silent/normal/turbo）
- 优先读取 3 套模式属性，若缺失则回退到旧单曲线
- 新增模式切换接口：数值和字符串两种
- 缓存最近温度 `last_temp`，切换模式后可立即按当前温度重算 PWM
- `manual_mode` 从 `1 -> 0` 时立即恢复自动温控

- `Documentation/devicetree/bindings/hwmon/pwm-fan.txt`
- `Documentation/hwmon/pwm-fan.rst`

## 3. 温控链路说明

本平台采用 `pwm-fan + rockchip,temp-trips + rockchip_system_monitor` 链路：

1. 系统温度变化触发 system monitor 通知
2. 按当前模式对应的 `temp-trips-*` 计算目标 state
3. 用该 state 索引 `cooling-levels-*` 得到 PWM 值
4. 通过 PWM 控制风扇转速

---

## 4. Sysfs 接口说明

先找到风扇对应 hwmon 目录（名字为 `pwmfan`）：

```bash
for d in /sys/class/hwmon/hwmon*; do
  [ "$(cat "$d/name")" = "pwmfan" ] && echo "$d"
done
```

假设结果为 `/sys/class/hwmon/hwmon3`，接口如下：

- `name` (RO)
  - 固定为 `pwmfan`
- `pwm1` (RW)
  - 手动 PWM，占空比范围 `0..255`
- `manual_mode` (RW)
  - `0`：自动温控
  - `1`：手动控速（温控不覆盖 `pwm1`）
- `fan_mode` (RW)
  - 数值模式：`0=silent`, `1=normal`, `2=turbo`
- `fan_mode_name` (RW)
  - 字符串模式：`silent|normal|turbo`
- `fan_mode_names` (RO)
  - 支持的模式列表
- `fan1_input` (RO，可选)
  - 风扇 RPM（仅硬件接了测速中断时可见）

## 5. 使用示例

### 5.1 自动模式下切换风扇模式

```bash
# 设置 normal
echo 1 | sudo tee /sys/class/hwmon/hwmon3/fan_mode

# 设置 silent
echo silent | sudo tee /sys/class/hwmon/hwmon3/fan_mode_name

# 查询当前模式
cat /sys/class/hwmon/hwmon3/fan_mode
cat /sys/class/hwmon/hwmon3/fan_mode_name
cat /sys/class/hwmon/hwmon3/fan_mode_names
```

### 5.2 手动模式下直接控速

```bash
# 开启手动模式
echo 1 | sudo tee /sys/class/hwmon/hwmon3/manual_mode

# 直接写 PWM
echo 120 | sudo tee /sys/class/hwmon/hwmon3/pwm1
echo 200 | sudo tee /sys/class/hwmon/hwmon3/pwm1

# 读取当前 PWM
cat /sys/class/hwmon/hwmon3/pwm1
```

### 5.3 恢复自动温控

```bash
echo 0 | sudo tee /sys/class/hwmon/hwmon3/manual_mode
```

> 说明：恢复自动后，驱动会按当前温度和当前模式立即重算并应用 PWM。

## 6. 参数调整原则

调整 `temp-trips-*` 与 `cooling-levels-*` 时建议遵循：

- `temp-trips` 递增且间隔不要太小（建议 >= 3~4C）
- `cooling-levels` 递增，且不超过 `255`
- 同档位下建议满足：`silent <= normal <= turbo`
- `temp-trips` 的 state 不可超过 `cooling-levels` 的最大下标
- 三种模式尽量使用同样的档位数量，方便维护和对比

---

## 7. 快速验证建议

1. 验证节点存在：`fan_mode`、`fan_mode_name`、`manual_mode`、`pwm1`
2. 自动模式切 `silent/normal/turbo`，观察 `pwm1` 变化
3. 手动模式写 `pwm1`，确认温控不覆盖
4. 切回自动，确认立即恢复温控
5. 若有 `fan1_input`，结合温度查看 RPM 响应是否符合预期
