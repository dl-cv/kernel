# RK3588 风扇控制说明

## 功能概述

本文汇总 `RK3588 + LubanCat 5IO` 平台当前风扇控制实现，覆盖 `silent`、`normal`、`turbo` 三种模式的设备树描述、驱动职责、sysfs 接口以及板端验证方法。

## 背景与目标

原 `doc/风扇控制说明.md` 已描述风扇多模式控制方案，但项目文档入口已统一迁移到 `docs/`。本文在保留原始结论的基础上，按当前文档规范重组为单一专题文档，便于后续原地更新。

## 文件清单

| 文件路径 | 类型 | 作用 | 调用方 | 依赖项 | 备注 |
| --- | --- | --- | --- | --- | --- |
| `arch/arm64/boot/dts/rockchip/rk3588-lubancat-5io.dts` | 基础设备树 | 描述 `pwm-fan` 节点及三套温控曲线 | 板级 DTS | PWM / thermal / hwmon | 三种模式曲线入口 |
| `drivers/hwmon/pwm-fan.c` | HWMON 驱动 | 解析三套 profile、切换模式并按当前温度重算 PWM | hwmon core / thermal framework | PWM / thermal / sysfs | 当前核心实现 |
| `Documentation/devicetree/bindings/hwmon/pwm-fan.txt` | 绑定文档 | 说明设备树属性约束 | 开发 / DTS 维护 | DTS | 与实现同步更新 |
| `Documentation/hwmon/pwm-fan.rst` | 驱动文档 | 说明用户态接口和行为 | 开发 / 调试 | hwmon | 与实现同步更新 |

## 功能结论

| 项目 | 当前实现 | 备注 |
| --- | --- | --- |
| 风扇模式 | `silent` / `normal` / `turbo` | 共 3 种 |
| 曲线数量 | 3 套独立温度-转速曲线 | 每种模式各自独立 |
| 档位数量 | 8 档 `state 0..7` | `temp-trips-*` 提供 7 个切换点 |
| 兼容策略 | 保留旧 `cooling-levels` / `rockchip,temp-trips` | 兼容旧配置，等价 `normal` |
| 用户入口 | sysfs | 同时支持数字模式和字符串模式 |
| 自动恢复 | `manual_mode` 从 `1 -> 0` 时立即恢复自动温控 | 使用最近温度 `last_temp` 重算 PWM |

## 关键函数

| 函数/方法 | 所在文件 | 作用 | 入参/出参 | 上下游依赖 | 备注 |
| --- | --- | --- | --- | --- | --- |
| `pwm-fan` profile 解析逻辑 | `drivers/hwmon/pwm-fan.c` | 读取 3 套模式曲线，缺失时回退旧单曲线 | 入参：OF 节点；出参：profile 数据 | probe -> OF 解析 | 建立 3 组 profile |
| 模式切换接口 | `drivers/hwmon/pwm-fan.c` | 提供数值和字符串两种切换入口 | 入参：模式值/模式名；出参：sysfs 写入结果 | 板端 shell -> sysfs | 支持 `silent/normal/turbo` |
| 温度重算逻辑 | `drivers/hwmon/pwm-fan.c` | 依据当前模式的 `temp-trips-*` 计算目标 state | 入参：当前温度；出参：目标档位 | thermal -> PWM | 自动模式核心 |
| PWM 应用逻辑 | `drivers/hwmon/pwm-fan.c` | 用目标 state 索引 `cooling-levels-*` 得到 PWM 值并写入 | 入参：state；出参：PWM 设置结果 | 重算逻辑 -> PWM framework | 直接决定转速 |
| `manual_mode` 恢复逻辑 | `drivers/hwmon/pwm-fan.c` | 从手动切回自动时按 `last_temp` 立即重算 | 入参：模式值；出参：sysfs 写入结果 | shell -> sysfs -> thermal/PWM | 避免恢复自动后仍停留旧 PWM |

## 运行链路

| 步骤 | 链路 | 作用 | 备注 |
| --- | --- | --- | --- |
| 1 | 温度变化 -> `rockchip_system_monitor` | 触发温控更新 | 上游温度来源 |
| 2 | 当前模式对应的 `temp-trips-*` | 计算目标 state | 不同模式阈值不同 |
| 3 | 当前模式对应的 `cooling-levels-*` | 将 state 映射为 PWM 值 | `silent <= normal <= turbo` 通常更合理 |
| 4 | PWM 输出 | 控制风扇转速 | 进入实际硬件执行 |

## 依赖关系

| 依赖项 | 类型 | 用途 | 所在位置 | 备注 |
| --- | --- | --- | --- | --- |
| `pwm-fan` | 内核驱动 | 风扇 PWM 控制核心 | `drivers/hwmon/pwm-fan.c` | 当前功能承载点 |
| `rockchip_system_monitor` | 温控链路 | 提供温度变化通知 | 板级热管理链路 | 驱动依赖其更新温度 |
| `manual_mode` | sysfs 节点 | 控制手动/自动模式切换 | `/sys/class/hwmon/hwmon*/manual_mode` | `0=自动`，`1=手动` |
| `pwm1` | sysfs 节点 | 手动模式下直接写 PWM | `/sys/class/hwmon/hwmon*/pwm1` | 范围 `0..255` |
| `fan_mode` | sysfs 节点 | 用数值切换风扇模式 | `/sys/class/hwmon/hwmon*/fan_mode` | `0=silent,1=normal,2=turbo` |
| `fan_mode_name` | sysfs 节点 | 用字符串切换风扇模式 | `/sys/class/hwmon/hwmon*/fan_mode_name` | `silent|normal|turbo` |
| `fan_mode_names` | sysfs 节点 | 查看支持的模式列表 | `/sys/class/hwmon/hwmon*/fan_mode_names` | 只读 |
| `fan1_input` | sysfs 节点 | 查看 RPM | `/sys/class/hwmon/hwmon*/fan1_input` | 仅硬件接测速时可见 |

## Sysfs 接口

| 节点 | 读写 | 作用 | 取值/示例 | 备注 |
| --- | --- | --- | --- | --- |
| `name` | RO | 确认当前 hwmon 节点 | `pwmfan` | 用于定位目录 |
| `pwm1` | RW | 手动模式下直接设置 PWM | `0..255` | 自动模式下可能被温控覆盖 |
| `manual_mode` | RW | 切换自动/手动 | `0` / `1` | `1` 时温控不覆盖 `pwm1` |
| `fan_mode` | RW | 数值切模式 | `0/1/2` | 对应三种模式 |
| `fan_mode_name` | RW | 字符串切模式 | `silent` / `normal` / `turbo` | 更便于人工调试 |
| `fan_mode_names` | RO | 查看模式列表 | `silent normal turbo` | 调试辅助 |
| `fan1_input` | RO | 查看风扇 RPM | 具体 RPM 数值 | 可选节点 |

## 调试命令

| 调试命令 | 执行位置 | 用途 | 示例 |
| --- | --- | --- | --- |
| 定位 `pwmfan` 目录 | 板端 | 找到实际 hwmon 路径 | `for d in /sys/class/hwmon/hwmon*; do [ "$(cat "$d/name" 2>/dev/null)" = "pwmfan" ] && echo "$d" && break; done` |
| 切到 `normal` | 板端 | 数值方式切模式 | `echo 1 | sudo tee "$HWMON_DIR/fan_mode"` |
| 切到 `silent` | 板端 | 字符串方式切模式 | `echo silent | sudo tee "$HWMON_DIR/fan_mode_name"` |
| 查看当前模式 | 板端 | 确认模式切换结果 | `cat "$HWMON_DIR/fan_mode"; cat "$HWMON_DIR/fan_mode_name"` |
| 开启手动模式 | 板端 | 允许直接写 PWM | `echo 1 | sudo tee "$HWMON_DIR/manual_mode"` |
| 手动设置 PWM | 板端 | 直接控速 | `echo 120 | sudo tee "$HWMON_DIR/pwm1"` |
| 恢复自动模式 | 板端 | 重新交给温控逻辑 | `echo 0 | sudo tee "$HWMON_DIR/manual_mode"` |
| 查看 RPM | 板端 | 验证转速反馈 | `cat "$HWMON_DIR/fan1_input"` |

## 参数调整原则

| 项目 | 建议 | 备注 |
| --- | --- | --- |
| `temp-trips-*` | 保持递增，间隔建议不小于 `3~4C` | 避免频繁抖动 |
| `cooling-levels-*` | 保持递增且不超过 `255` | 超出无意义 |
| 三种模式相对关系 | 尽量满足 `silent <= normal <= turbo` | 便于理解和维护 |
| 档位数量 | 三种模式尽量保持一致 | 方便横向对比 |
| 阈值与档位关系 | `temp-trips` 的 state 不应超过 `cooling-levels` 最大下标 | 否则会出现配置错误 |

## 快速验证

| 步骤 | 检查点 | 预期 |
| --- | --- | --- |
| 1 | `fan_mode`、`fan_mode_name`、`manual_mode`、`pwm1` 是否存在 | 节点齐全 |
| 2 | 自动模式切 `silent/normal/turbo` | `pwm1` 或风扇转速有差异 |
| 3 | 手动模式写 `pwm1` | 温控不会立即覆盖 |
| 4 | 切回自动模式 | 驱动按当前温度立即重算 PWM |
| 5 | 若存在 `fan1_input` | RPM 与模式/PWM 变化相符 |
