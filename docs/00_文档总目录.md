# 文档总目录

## 摘要

本目录用于记录鲁班猫 RK3588 内核树中的设备树、驱动配置和板级适配信息，避免后续重复搜索上下文。

## 说明

- 当前项目文档入口统一收敛到根级 `docs/`，`docs/00_文档总目录.md` 为全局唯一索引。
- `IMX296` 相关：**板级与触发链路**以 `docs/06_IMX296_cam1_适配记录.md` 为准；**曝光/增益与 v4l2-ctl** 以 `docs/07_IMX296_v4l2曝光与增益说明.md` 为准；二者交叉处只在一侧展开，另一侧用「文档分工」表互链。
- 相机 XTRIG 与外部硬触发以 SoC `PWM14_M2` + `trigger-dev` 为准；GD32 相关 DTS/驱动已从树内删除，原专题文档已移除，`docs/plans/2026-03-25_gd32_i2c_device_plan.md` 仅保留废弃说明。
- 风扇控制相关若继续调整曲线或用户接口，应优先更新 `docs/08_RK3588风扇控制说明.md`。
